## 规则要点（5 条，均有官方原文）

1. **三赛道**：Classic（开赛才动工）/ Extend Open Source（带自己的开源仓库加新功能）/ Ship a Feature——**第二条最适合你正在做的 Web3 钱包**。
2. **提交物**＝公开 GitHub 仓库 + 2–4 分钟真人 demo 视频（禁 AI 配音）+ 勾选最多 3 个赞助商赏金。
3. **评审五维**：技术 / 原创 / 实用 / 可用性 / WOW；demo 视频和文档占一半权重。
4. **IP 归参赛者**；官方第 8 条明文把你的 LinkedIn/GitHub/项目信息共享给赞助商——被公司看见的官方通道（Mumbai 的 1inch 赏金页直接挂了招聘链接）。
5. **版本纪律**：开赛起每天真实 commit，一个"大 commit"会被取消资格。
